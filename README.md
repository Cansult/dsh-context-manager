# Context manager

目前上下文既是模型过去工作的路径, 又是要展示给后续工作的背景; 也许两者应该分离

`/compact` 和 子 Agent 实现了这个功能的一部分 (将过程没什么意义的任务路径扔掉, 只保留对模型接下来有用的信息), 但是我们在探索过程中之前的上下文难免会出现一些不愉快不想保留的部分

虽然现在上下文普遍都长了, 也有自动压缩, 不太容易达到硬限制, 但是不干净的上下文还是容易让模型流口水; 或许直接改写 context 也是和模型交互的一部分, 也可能只是我强迫症犯了

不如把这部分显式暴露给用户, 简单许愿了一版:

## 用法

### 安装

```
dsh plugin --profile web add github:cansult/dsh-context-manager
```

### 命令

```
展示上下文列表: 
/ctx-mod list

由模型压缩列表中 index 从 2 到 6 的部分:
/ctx-mod compact 2-6

将列表中 index 为 2 4 5 6 的部分替换为用户输入的内容:
/ctx-mod replace 2,4-6 你已经完成了 xxx 部分的探索, 结论是 xxx

扔掉 index 为 2 的部分:
/ctx-mod drop 2
```

当然扔掉特别靠前的 context 对缓存不是特别友好, 而最后一次回复又是经常需要操作的 (以前都是直接分叉会话解决这个问题), 所以为最后一个 context 的操作提供了简化的命令

```
压缩最后一次模型输出:
/ctx-c

替换最后一次模型输出:
/ctx-r 新内容

丢弃最后一次模型输出:
/ctx-d
```

调试命令: 

```
当前的完整上下文:
/ctx-mod debug
```
